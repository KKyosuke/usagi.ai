# `close` — セッションを終了

## 概要

`close` コマンドは、現在の `usagi hop` セッションを終了し、プロジェクト選択画面（`usagi open` のTUI）に戻ります。

## 使い方

```
close
```

引数はありません。

## 動作

`close` を実行すると、hop TUI が終了し、`usagi open` のワークスペースセレクター画面に戻ります。
プロジェクト選択画面から別のプロジェクトを開いたり、アプリを終了したりできます。
